# Portfolio v2 — Andre Veltens

Personal portfolio built with Angular 21, showcasing frontend, iOS and backend projects.

**Live:** [veltens.info](https://veltens.info)

## Tech Stack

- **Angular 21 with Typescript** — Standalone components, signals, zoneless
- **WCAG 2.2 AA** — Fully tested with VoiceOver and keyboard navigation
- **Transloco** — Multi-language routing with URL-based locale switching (DE/EN)
- **modern CSS** — `light-dark()`, container queries, no framework

## Features

- Dark / Light mode
- Draggable project overlay windows
- Contact form with PHP backend
- Responsive design

## Development

```bash
ng serve
```
